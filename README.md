<h1>Quiz Conhecimentos Gerais</h1>

<h2> Sobre </h2>
<p> Projeto realizado através da 'Imersão Dev' da Alura. Trata-se de um quiz de conhecimentos gerais com 10 perguntas numeradas de forma aleatória, onde o usuário deve escolher uma resposta entre 5 alternativas. O projeto foi realizado através do site CodePen, utilizando como linguagem de programação o Java-Script.</p>
